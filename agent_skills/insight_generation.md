# Insight Generation Skill

## Purpose

Transform raw research findings into **novel connections**, **unexpected patterns**, and **actionable hypotheses** - applicable to ANY research domain.

## Core Principle

Insight generation is **synthesis**, not summary. It's asking "What does this MEAN?" not "What did I find?"

---

## Universal Insight Generation Framework

### 1. **Pattern Recognition (See What Repeats)**

**Meta-Questions:**

- What patterns emerge **across** sources?
- Which findings **consistently replicate**?
- What **unexpected correlations** appear?
- Which variables **cluster together**?

**Application Process:**

```
think_strategically: "Reviewing multiple sources..."

LOOK FOR:
- Consistent findings across studies/contexts
- Recurring themes or mechanisms
- Statistical patterns (effect sizes, directions)
- Unexpected co-occurrences

PATTERN = "Across [N] sources, [X] consistently relates to [Y]"
```

**Example Template:**

```
"Across [domain], I notice:
- Finding A appears in [sources 1, 2, 3]
- Finding B consistently shows [pattern]
- Unexpected: C and D correlate despite [expectation]

INSIGHT: This suggests [underlying mechanism/principle]"
```

### 2. **Novel Connections (Bridge Domains)**

**Meta-Questions:**

- How do these findings relate to **other domains**?
- What **parallels** exist in different systems?
- Which **mechanisms** could explain multiple phenomena?
- What **unifying frameworks** emerge?

**Application Process:**

```
think_strategically: "Making cross-domain connections..."

FINDING in Domain A: [X]
FINDING in Domain B: [Y]
PARALLEL: Both show [similar pattern]

NOVEL INSIGHT: Could [shared mechanism Z] explain both?
```

**Connection Types:**

- **Cross-disciplinary**: Economics → Biology, Physics → Sociology
- **Cross-scale**: Molecular → Organism → Population
- **Cross-temporal**: Historical → Contemporary
- **Cross-contextual**: Lab → Field, Theory → Practice

### 3. **Hypothesis Generation (Make Predictions)**

**Meta-Questions:**

- What **testable predictions** arise from findings?
- Which **mechanisms remain untested**?
- What **experiments** could validate insights?
- Which **interventions** are implied?

**Application Process:**

```
think_strategically: "From findings, what predictions follow?"

OBSERVATION: [Empirical finding]

TESTABLE HYPOTHESES:
H1: If [X], then [Y] (mechanistic)
H2: [X] will predict [Y] (predictive)
H3: Modifying [X] will change [Y] (interventional)

NEXT STEPS: [How to test these]
```

**Hypothesis Quality Checklist:**

- ✓ **Specific**: Clear variables and predicted relationships
- ✓ **Testable**: Can be empirically evaluated
- ✓ **Falsifiable**: Could be proven wrong
- ✓ **Mechanistic**: Explains HOW/WHY, not just correlation

### 4. **Contradiction Resolution (Explain Disagreement)**

**Meta-Questions:**

- Why do sources **disagree**?
- What explains **conflicting results**?
- Which **contextual differences** matter?
- Can contradictions **reveal** something new?

**Application Process:**

```
think_strategically: "Sources disagree. Why?"

SOURCE A: Finds [X]
SOURCE B: Finds [opposite of X]

ANALYSIS:
- Different contexts? [A in lab, B in field]
- Different methods? [A survey, B experiment]
- Different populations? [A students, B professionals]

INSIGHT: This suggests [boundary condition] - X is true when [condition], not when [other condition]
```

### 5. **Actionable Directions (What Next?)**

**Meta-Questions:**

- What should be **investigated next**?
- Which **experiments** are most promising?
- What **practical applications** exist?
- Which **policy/practice changes** are supported?

**Application Process:**

```
think_strategically: "Based on insights, what actions follow?"

ACTIONABLE DIRECTIONS:
1. IMMEDIATE: [Low-hanging fruit research/application]
2. SHORT-TERM: [Requires 1-2 studies/pilots]
3. MEDIUM-TERM: [Requires systematic program]
4. LONG-TERM: [Paradigm shift/major change]
```

## Domain-Agnostic Insight Process

### Step 1: Divergent Thinking (Breadth)

**Goal**: Generate multiple possible interpretations

```
think_strategically: "What could these findings mean?"

INTERPRETATION 1: [Explanation A]
INTERPRETATION 2: [Explanation B]
INTERPRETATION 3: [Explanation C]
...
Generate 5-10 without judging
```

### Step 2: Convergent Thinking (Depth)

**Goal**: Evaluate and prioritize interpretations

```
think_strategically: "Which interpretation is best supported?"

INTERPRETATION 1: [Evidence for/against]
INTERPRETATION 2: [Evidence for/against]
INTERPRETATION 3: [Evidence for/against]

MOST SUPPORTED: [Interpretation X because...]
```

### Step 3: Synthesis (Integration)

**Goal**: Combine insights into cohesive narrative

```
"The convergence of [evidence type 1], [evidence type 2], and [evidence type 3]
suggests [phenomenon] operates through [mechanism], which has implications for
[practical application/theoretical understanding]."
```

### Step 4: Validation (Reality Check)

**Goal**: Test insights against evidence

```
think_strategically: "Does this insight hold up?"

CHECKLIST:
□ Consistent with existing literature?
□ Mechanistically plausible?
□ Testable/falsifiable?
□ Generalizable or context-specific?

IF NO to any → Revise or note as speculative
```

## Generic Insight Templates

### Template 1: Unifying Framework

```
"Previously viewed as separate, [A] and [B] can be understood as
manifestations of [unifying principle C], which explains [findings 1, 2, 3]."
```

### Template 2: Mechanistic Chain

```
"[Initial cause] → [Intermediate step 1] → [Intermediate step 2] → [Final outcome],
providing a process-level explanation for [phenomenon]."
```

### Template 3: Comparative Insight

```
"Unlike [context A] which shows [pattern 1], [context B] exhibits [pattern 2],
suggesting [contextual factor X] moderates [relationship]."
```

### Template 4: Translational Insight

```
"Finding [X] in [basic research context] suggests [practical application Y]
could work in [applied context] given [parallels]."
```

```
think_strategically (applying insight_generation):

PATTERNS: [What repeats across sources]

HYPOTHESES: [Testable predictions]
CONTRADICTIONS: [Disagreements and why]
ACTIONS: [What to do next]

```

**Then document:**

```
write_file or edit_file:

- Novel understanding
- Mechanistic explanation
- Practical implications
- Future directions
```

## Examples Across Domains

### Example 1: Social Science

```
think_strategically (insight_generation):

DOMAIN: Workplace productivity
FINDINGS:
- Remote work increases output for experienced workers
- Remote work decreases output for new hires
- Mentorship frequency dropped 60% in remote settings

PATTERN: Experience moderates remote work effectiveness
INSIGHT: Remote work disrupts informal learning/mentorship
HYPOTHESIS: Hybrid model preserves productivity AND mentorship
ACTION: Test hybrid schedules with mentorship metrics
```

### Example 2: Physical Science

```
think_strategically (insight_generation):

DOMAIN: Material science
FINDINGS:
- Material A strong at high temp, weak at low
- Material B opposite pattern
- Both share crystal structure

PATTERN: Temperature effects inverse for similar structures
INSIGHT: Crystal structure alone doesn't predict thermal behavior
HYPOTHESIS: Bonding type (not structure) determines thermal properties
ACTION: Systematically vary bonding while holding structure constant
```

### Example 3: Historical Research

```
think_strategically (insight_generation):

DOMAIN: Economic history
FINDINGS:
- Trade route disruptions preceded 5/7 major conflicts studied
- Resource scarcity appeared 2-3 years before all 7 conflicts
- Diplomatic breakdown followed (not preceded) scarcity

PATTERN: Economic precedes political breakdown
INSIGHT: Resource conflicts may be misattributed to ideological causes
HYPOTHESIS: Modern resource mapping could predict conflict risk
ACTION: Apply model to current trade/resource data
```

## Red Flags (Avoid These)

❌ **Over-interpretation**: "X proves Y" (from limited data)
❌ **Confirmation bias**: Only noting supporting evidence
❌ **Vague insights**: "It's complicated" or "More research needed"
❌ **Unfalsifiable**: "Hidden factors could explain everything"

✅ **Good Insights**:

- Specific and mechanistic
- Supported by data
- Generate testable predictions
- Acknowledge limitations
- Connect to broader understanding

## Remember: Universal Principles

1. **Insights are synthetic** - they combine, not summarize
2. **Insights are generative** - they produce new questions/hypotheses
3. **Insights are mechanistic** - they explain HOW/WHY, not just WHAT
4. **Insights are actionable** - they suggest next steps
5. **Insights are honest** - they acknowledge uncertainty and limitations

This framework applies whether researching climate systems, literary themes, or neural networks.
