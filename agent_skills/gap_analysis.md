# Gap Analysis Skill

## Purpose

Provide a **thinking framework** to identify what's missing, contradictory, or unexplored in research - applicable to ANY domain.

## Core Principle

Gap analysis is about asking **structured questions** that reveal blind spots, regardless of subject matter.

---

## Universal Gap Analysis Questions

### 1. **Completeness Dimension: What's Missing?**

**Meta-Questions** (domain-agnostic):

- What **types of evidence** are absent? (qualitative vs quantitative, primary vs secondary)
- Which **populations/contexts** are underrepresented? (demographics, geographies, time periods)
- What **scales of analysis** are missing? (micro vs macro, individual vs system-level)
- Which **methodological approaches** haven't been tried? (experimental, observational, computational)

**Application Process:**

```
think_strategically: "Reviewing current evidence base..."

ASK YOURSELF:
1. Do I have both quantitative AND qualitative evidence?
2. Do findings span different populations/contexts?
3. Are multiple methodological approaches represented?
4. What time scales are covered? (short-term, long-term, longitudinal)

IDENTIFY GAPS by noting what's missing from each dimension
```

### 2. **Perspective Dimension: What Angles Are Unexplored?**

**Meta-Questions:**

- What **alternative explanations** haven't been considered?
- Which **theoretical frameworks** could provide different insights?
- What **cross-domain perspectives** might inform this? (e.g., economics applied to biology)
- Which **stakeholder perspectives** are absent? (patients, practitioners, policymakers)

**Application Process:**

```
think_strategically: "What lenses haven't been applied?"

PERSPECTIVE CHECKLIST:
□ Examined from multiple theoretical frameworks?
□ Considered reverse causality / bidirectional effects?
□ Applied interdisciplinary approaches?
□ Included diverse stakeholder viewpoints?

UNEXPLORED ANGLES = unchecked boxes
```

### 3. **Consistency Dimension: What Contradicts?**

**Meta-Questions:**

- Where do sources **disagree**?
- What **contradictory findings** exist?
- Do results vary by **context/method**?
- What explains **discrepancies**?

**Application Process:**

```
think_strategically: "Mapping contradictions..."

CONTRADICTION MATRIX:
Source A says: [claim X]
Source B says: [contradictory claim Y]

WHY? Different:
- Methodologies?
- Sample characteristics?
- Measurement approaches?
- Historical periods?

INSIGHT: Contradiction reveals [what this tells us about the phenomenon]
```

### 4. **Depth Dimension: What Lacks Detail?**

**Meta-Questions:**

- Which **mechanisms** remain unclear?
- What **causal pathways** are poorly understood?
- Where do we need more **granular analysis**?
- Which **boundary conditions** are undefined?

**Application Process:**

```
think_strategically: "Assessing explanatory depth..."

DEPTH AUDIT:
□ Do we know WHAT happens? (descriptive)
□ Do we know HOW it happens? (mechanistic)
□ Do we know WHY it happens? (theoretical)
□ Do we know WHEN/WHERE it happens? (boundary conditions)

SHALLOW AREAS = need deeper investigation
```

### 5. **Utility Dimension: What's Impractical/Untested?**

**Meta-Questions:**

- How does this **translate to practice**?
- What **implementation barriers** exist?
- Which **real-world applications** haven't been tested?
- What **scalability/feasibility** questions remain?

## Domain-Agnostic Gap Analysis Process

### Step 1: Inventory (What Do You Have?)

```
think_strategically: "Cataloging current knowledge..."

ORGANIZE BY:
- Evidence types: [list]
- Methods used: [list]
- Populations studied: [list]
- Contexts examined: [list]
```

### Step 2: Contrast (What Do You NOT Have?)

```
think_strategically: "Identifying absences..."

FOR EACH CATEGORY:
- Evidence types: Missing [X, Y, Z]
- Methods: Haven't tried [A, B, C]
- Populations: Underrepresented [P, Q, R]
- Contexts: Unexplored [C1, C2, C3]
```

### Step 3: Prioritize (Which Gaps Matter Most?)

**Universal Prioritization Criteria:**

| Criterion       | Question                                                 | Weight            |
| --------------- | -------------------------------------------------------- | ----------------- |
| **Impact**      | Would filling this gap change core conclusions?          | High              |
| **Feasibility** | Can this gap be addressed with available resources/data? | Medium            |
| **Urgency**     | Does decision-making depend on this?                     | Context-dependent |

```
write_todos: Prioritize based on Impact × Feasibility

HIGH PRIORITY: [gaps that are both high-impact AND feasible]
MEDIUM: [high-impact but low-feasibility OR low-impact but easy]
LOW: [low-impact AND low-feasibility]
```

### Step 4: Plan Gap-Filling

```
write_todos:
- [ ] HIGH: [specific action to fill critical gap]
- [ ] MEDIUM: [action for medium-priority gap]
- [ ] Document unfillable gaps in Limitations
```

## Generic Templates (Adapt to Your Domain)

### Template 1: Evidence Gap

```
"Current evidence is limited to [type] data from [population] using [method].
Missing: [Other evidence types] from [other populations] using [other methods].
This gap limits our ability to [specific limitation]."
```

### Template 2: Mechanistic Gap

```
"We know THAT [phenomenon occurs], but not HOW/WHY.
Proposed mechanisms ([A, B, C]) require [type of investigation] to validate.
Until then, [practical implication remains uncertain]."
```

### Template 3: Contradictory Findings

```
"Study/Theory A found [X], while Study/Theory B found [opposite of X].
Possible explanations: [methodological differences, contextual factors, etc.].
Resolving this requires [specific comparative analysis]."
```

## Integration with Think Strategically

**After gathering research:**

```
think_strategically (applying gap_analysis):

"Reviewing evidence on [topic]...

COMPLETENESS: Mostly quantitative, lacking qualitative depth
PERSPECTIVE: Only examined from [framework A], not [framework B]
CONSISTENCY: Source X and Y contradict on [specific point]
DEPTH: Know correlation, but not causation
UTILITY: No implementation studies

PRIORITY GAPS: [most critical 2-3 to address]"
```

**Then update todos:**

```
write_todos:
- [ ] Fill completeness gap: Search for qualitative studies
- [ ] Address contradiction: Compare methodologies of X vs Y
- [ ] Document depth gap in Limitations if unfillable
```

## Examples Across Domains

### Example 1: Literature Review (Any Field)

```
think_strategically (gap_analysis):

DOMAIN: Education policy
INVENTORY: 15 studies on standardized testing impact
GAPS IDENTIFIED:
  - Completeness: All quantitative test scores, no classroom observation
  - Perspective: Teacher view absent (only student outcomes studied)
  - Consistency: Urban studies show benefit, rural show harm

ACTION: Search for qualitative + rural context studies
```

### Example 2: Empirical Study (Any Field)

```
think_strategically (gap_analysis):

DOMAIN: Software engineering
INVENTORY: Analyzed code review effectiveness
GAPS:
  - Scale: Only studied small teams (<10), not enterprise scale
  - Context: Tech companies only, not non-profits/government
  - Method: Survey data, no behavioral observation

ACTION: Acknowledge scale/context limitations, suggest observational follow-up
```

---

## Remember: Universal Principles

1. **All research has gaps** - your job is to identify them systematically
2. **Gaps are dimensional** - completeness, perspective, consistency, depth, utility
3. **Prioritize ruthlessly** - not all gaps are equally important
4. **Document honestly** - unaddressed gaps strengthen credibility
5. **Use gaps generatively** - they reveal future research opportunities
